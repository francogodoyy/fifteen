#  Fifteen — Invitación Digital de 15 Años

Invitación web interactiva desarrollada para una fiesta de 15 años. Reemplaza la invitación física tradicional por una experiencia digital animada, con cuenta regresiva al evento, galería de fotos y confirmación de asistencia vía WhatsApp.

 **Demo en vivo:** [fifteen-three.vercel.app](https://fifteen-three.vercel.app)

## ✨ Funcionalidades

-  **Efectos visuales de partículas** — Animación de fondo con partículas decorativas
-  **Cuenta regresiva** — Contador en tiempo real hacia la fecha del evento
-  **Galería con carrusel** — Fotos de la festejada con slider interactivo
-  **Confirmación de asistencia** — Botón directo a WhatsApp para confirmar presencia
-  **Animaciones de entrada** — Transiciones y efectos con Framer Motion
-  **Diseño responsive** — Adaptado para verse bien en celular y desktop

##  Correr el proyecto localmente

### 1. Clonar el repositorio

```
git clone https://github.com/francogodoyy/fifteen.git
cd fifteen
```

### 2. Instalar dependencias

```
npm install
```

### 3. Iniciar el servidor de desarrollo

```
npm start
```

Abrir [http://localhost:3000](http://localhost:3000) en el navegador.
